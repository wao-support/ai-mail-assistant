# AIメールアシスタント - 開発・運用マニュアル（人間向け）

本ドキュメントは、この「AIメールアシスタント」プロジェクトを管理・拡張していく**人間の開発者および運用担当者**のためのガイドラインです。
AIエージェント向けのシステム指示書は `AI_INSTRUCTIONS.md` を参照してください。

---

## 1. プロジェクトの基本情報
*   **用途:** お弁当デリ・社食DELI等のCS対応、および営業部門向けのメール返信作成自動化ツール。
*   **特徴:** Gemini API（ストリーミング出力）を活用し、業務に最適化された3つの独自UI（汎用返信、汎用新規作成、CS専用画面）を提供。
*   **技術構成:** Vanilla JavaScript (React等のフレームワーク不使用)、HTML5、CSS3。バックエンドとしてGoogle Apps Script (GAS) を利用。

## 2. 開発の基本スタイル：「AI駆動開発（二刀流）」
本プロジェクトは、人間のエンジニアがゼロからコードを書くのではなく、**AIをディレクションして構築するアプローチ**を前提としています。
以下の2つのAIツールを役割分担させて開発を進めてください。

### ① Antigravity（Cursor等エディタ内AI）＝「設計・実装担当」
*   **役割:** UIの追加、新しい画面の設計、複雑な新機能（例：プロンプト置き場機能など）のコーディング。
*   **使い方:** 
    *   エディタ上でAIに話しかけ、「`AI_INSTRUCTIONS.md` に従って、こういう機能を追加して」と指示を出します。
    *   コードの書き換えが行われたら、ブラウザ上で動作確認（ローカルサーバー等でのテスト）を行います。

### ② Claude Code（ターミナル内AI）＝「微調整・Git操作担当」
*   **役割:** GitHubへのコミット・プッシュ、修正漏れの確認、軽微なバグ修正、一括置換など。
*   **使い方:** 
    *   ターミナルを開き、コマンド `claude` を実行してチャットを開始します。
    *   Antigravityで作った機能が動くことを確認したら、「`今の変更をすべてコミットして、"〇〇機能の追加" とわかりやすいメッセージをつけて main ブランチに push して`」と指示を出します。
    *   「〇〇ファイルのエラーだけ直しておいて」などの最後の頼み事も得意です。

## 3. 人間が守るべき保守のルール

1.  **AIへの指示書（AI_INSTRUCTIONS.md）のメンテナンス**
    *   新しいルールや「AIにやってほしくないこと」が増えた場合は、人間が `AI_INSTRUCTIONS.md` を書き換えてください。AIはそこを読んでから動きます。
    *   例：「デザインテーマを青色基調に変えたい」と決まったら、指示書に「ベースカラーは青色（#0055ff）とすること」と追記しておきます。
2.  **GAS連携の管理**
    *   プロンプト置き場のデータや、利用状況のログは Google Spreadsheet (Apps Script) に送信されます。
    *   GAS側のコード (`prompt_gas_api.gs` など) を変更した場合は、**必ずGASエディタ上で「新しいデプロイ」を作成し、WebアプリのURLを更新**してください。
    *   更新されたGASのURLは、本ツールの「設定（歯車マーク）」から再登録する必要があります。（※旧URLのままだと新機能が動きません）
3.  **直接 main ブランチをいじらない（推奨）**
    *   複数人で開発するようになった場合や、大きな改修をする場合は、本番環境（main）が壊れないようブランチを切ってください。
    *   Claude Codeに「`新機能用のブランチを作って作業して`」と頼むのが一番安全です。

## 4. 各ファイルの役割
*   `index.html` / `app.js`: 【汎用返信】受信メールを元に返信を作るメイン機能
*   `create.html` / `create.js`: 【汎用新規】ゼロから用件を伝えてメールを生成する機能
*   `obento_cs.html` / `obento_cs.js`: 【CS専用】対応方針（確認/了解/拒否）や参照情報を指定する専用機能
*   `prompts.html` / `prompts.js`: 【プロンプト置き場】社内の共有指示テンプレート一覧と追加・編集
*   `AI_INSTRUCTIONS.md`: AI用システムプロンプト（絶対ルール）
*   `README.md`: 本ファイル（人間用ガイドライン）
