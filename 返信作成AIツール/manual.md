# AIメールアシスタント 利用マニュアル

本システムは、日々のメール対応業務を効率化するためのAI（Gemini API）を活用したメール作成補助ツールです。
用途に合わせて以下の3つの機能が用意されています。

---

## 1. 汎用返信
**【目的】**
受信したメールに対する返信文を、ビジネスの場面にふさわしい適切な敬語やマナーに従って自動作成します。

**【使い方】**
1. **① 受信メール本文**: 返信したいメールの本文をコピーして貼り付けます。
2. **自動判定**: 「カテゴリを自動判定」ボタンを押すと、AIが内容を分析して自動でカテゴリを選択します（手動で選択することも可能です）。
3. **③ 返信トーン**: 丁寧、簡潔・端的、謝罪など、状況に合ったトーン（文体）を選びます。
4. **④ 追加指示（任意）**: 「〇〇について追加で質問してほしい」「明日の14時で調整をお願いする」といった具体的な指示があれば入力します。
5. **「返信文を生成」をクリック**: 画面右側に件名と本文の案が出力されます。
6. **コピーして利用**: 「コピー」ボタンをクリックするとクリップボードに保存されるので、お使いのメールソフトにそのまま貼り付けて送信できます。

---

## 2. 汎用新規
**【目的】**
受信メールに対する返信ではなく、ゼロから新しく案内や依頼などのビジネスメールを作成する際に使用します。

**【使い方】**
1. **① 宛名（会社名等） / ② 宛名（お名前）**: 送信先の会社名や担当者名を入力します（入力するとメールの冒頭に自動で挿入されます）。
2. **③ 伝えたい内容**: メインの用件を箇条書きや短い文章で入力します。（例：「明日の会議を14時に変更してほしい」など）
3. **④ 返信トーン**: 用途に応じた返信トーンを選択します。
4. **「メールを生成」をクリック**: 画面右側に宛名、挨拶、指定した用件の丁寧な展開、結び、署名がすべて揃ったメール案が作成されます。
5. **コピーして利用**: 「コピー」ボタンを押してメールソフトで利用します。

---

## 3. CS専用（お弁当デリ カスタマーサポート専用）
**【目的】**
お弁当デリのカスタマーサポート業務に特化し、FAQや過去の対応ログを参照して、より専門的で正確な返信文を生成します。

**【使い方】**
1. **① 受信メール本文**: お客様からの受信メールを貼り付けます。
2. **② お客様の宛名情報**: 会社名やお名前を入力します。
3. **③ 対応方針・具体的な案内内容**: お客様のご要望に対して「確認」「了解」「拒否」などのスタンスを選び、具体的な案内事項があれば入力します。
4. **④ 参照データ**: より正確な回答を作るため、「FAQを参照する」「過去の類似対応ログを参照する」にチェックを入れることができます。
5. **⑤ 返信トーン**: 目的に合ったトーンを選びます。
6. **「CS向け返信文を生成」をクリック**: 自動で問い合わせカテゴリ（注文変更、配送遅延など）が判定され、コールセンター基準のクッション言葉などを用いたメール案が出力されます。

---

### 【共通機能】設定画面（右上の歯車アイコン）
全機能のベースとなる以下の設定を行えます。設定アイコンをクリックして確認してください。

* **Gemini API Keyの確認**: システムを利用するためのAPIキーが設定されています。
* **メール末尾の署名**: 生成されるすべてのメールの末尾に自動で挿入される署名を変更・保存できます。部署名のご自身の名前に書き換えてご利用ください。
