# 企業情報ブラウザ巡回ワークフロー

## 概要
営業リスト作成ツールの「要手動確認」シートに載っているイベントURLを、Antigravityブラウザエージェントで巡回して企業情報を抽出し、スプレッドシートに反映する。

## 手順

// turbo-all

### 1. 未確認URLの取得
```bash
cd /Volumes/SSD-PGU3C/返信作成AIツール/BP営業サポートツール
PYTHONPATH=. python3 /tmp/get_urls.py
```
→ 未確認のイベントURLリストを確認する

### 2. ブラウザエージェントで巡回
以下のフォーマットで5〜10件ずつURLを指定してブラウザエージェントに巡回させる：

**指示テンプレート:**
> 以下のイベントURLをブラウザで巡回して、各サイトから企業情報を抽出してください：
> 1. [URL] ([イベント名])
> 2. [URL] ([イベント名])
> ...
>
> 各サイトで以下を確認してください：
> - 主催企業名
> - 運営会社名
> - 事務局名
> - 会社概要ページURL
> - 問い合わせページURL

### 3. 結果を「要手動確認」シートに反映
抽出結果を `/tmp/update_manual_review.py` の `extracted` リストに追加して実行する。

### 4. 進捗確認
スプレッドシートの「要手動確認」シートで「確認ステータス」列が「確認済」になっている行を確認する。
